# Upstream inspection

Inspected 2026-10-31 using the GitHub API, actual release RPMs, and the matching source archive. These are observations, not hardcoded synchronization versions.

- Project: <https://github.com/autobrr/mkbrr>, default branch `develop`.
- Releases: <https://github.com/autobrr/mkbrr/releases>; the paginated Releases API reported 37 releases at inspection time. Latest stable: `v1.27.0` (2026-10-06); next stable releases `v1.26.0`, `v1.25.1`.
- GoReleaser: <https://github.com/autobrr/mkbrr/blob/develop/.goreleaser.yml>. Also read the exact file in the matching release archive. Linux Go targets are amd64, arm64, arm with GOARM=6; CGO is disabled. nFPM generates RPM, DEB, APK, and some Arch packages. No RPM signing configuration was present.
- Release workflow: <https://github.com/autobrr/mkbrr/blob/develop/.github/workflows/release.yml>. Runs GoReleaser for `v*` tags after tests/PGO generation. GUI archives are uploaded separately and are not RPMs. Container architectures are NOT evidence that matching RPMs exist.
- Manifest: `mkbrr_1.27.0_checksums.txt`, SHA-256 GNU-style entries, including all three RPM assets. Stable tag format `vMAJOR.MINOR.PATCH`; RPM version drops `v`.

`rpm -qip` reported `Signature: (none)` for the inspected amd64 package. `rpmkeys --checksig --verbose` reported valid header/payload SHA-256 digests and no cryptographic signature. The file list contains `/usr/bin/mkbrr`; no scriptlets were reported. Epoch is zero, package release is `1`, and License header is empty upstream. The implementation never mistakes digest success alone for a signed package.

Matching source: the tag source archive contains root `LICENSE` (GNU GPL version 2), `go.mod`, `go.sum`, `.goreleaser.yml`, `.github/workflows/release.yml`, Makefile and application sources. Source control files are read without extracting untrusted tar members or executing upstream scripts. Source commit is resolved dynamically and the archive is pinned to it. Its root CLI module uses Go 1.27.0; the publisher does not need Go and never compiles it. `gui/` is a separate module and not the CLI RPM payload.

The original source and dependency source archives are mirrored alongside RPMs. A source link alone is not used as the repository's GPL corresponding-source distribution strategy. The upstream PGO profile is generated by the archived release workflow; no reproducibility claim is made.

Official GitHub Actions versions were discovered through their Releases API at implementation time and pinned to their release SHAs: checkout 7.0.1, configure-pages 6.0.0, upload-pages-artifact 5.0.0, deploy-pages 5.0.1. Dependabot monitors their immutable pins.
